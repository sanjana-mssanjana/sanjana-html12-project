Responsive Webpage Demo

Resize the browser window (or open this on your phone) to see the layout adapt — the navigation collapses into a hamburger menu and the card grid reflows automatically.

Feature One

This card grid uses CSS Grid with media queries to go from 3 columns → 2 columns → 1 column as the screen shrinks.

Feature Two

Font sizes, spacing, and layout all scale down gracefully for smaller devices.

Feature Three

The navbar swaps from a horizontal link list to a tappable hamburger menu below 600px width.
